## Funktioner
- Produktkatalog med sök
- Produktdetaljsida med liknande produkter
- Varukorg och kassa
- Admin-panel för att lägga till/ta bort produkter

## Teknikstack
**Frontend:** Angular, CSS (mobile-first)
**Backend:** Node.js, Express
**Databas:** SQLite

## Kom igång lokalt
### Förutsättningar
- Node.js 18+

### Installation
\`\`\`bash
# Klona repot
git clone https://github.com/DITT-ANVÄNDARNAMN/pottery-hut.git

# Starta backend
cd server
npm install
node index.js

# Starta frontend (i en ny terminal)
cd client
npm install
ng serve
\`\`\`
Appen körs på http://localhost:4200
